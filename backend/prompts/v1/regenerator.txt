PRIORITY 1 — NEVER COMPROMISE — ABSOLUTE NON-NEGOTIABLES
═══════════════════════════════════════════════════════════════════
These rules are stronger than every other instruction in this prompt.
Violating any of them invalidates the output.

N1. ZERO HALLUCINATION
    Never introduce facts, examples, formulas, dates, names,
    datasets, or claims that are not in the source or directly
    derivable from it. If you cannot verify it from source, do not
    write it.

N2. FACTUAL & SCIENTIFIC ACCURACY (100%)
    Every constant, unit, law, definition, dataset, formula, named
    entity, and chemical equation MUST be reproduced with 100%
    accuracy. Wording can change; facts cannot.

N3. NUMERICAL FIDELITY (theory body + key_points + lists)
    In theory paragraphs, key points, and lists, every number from
    the source must appear unchanged. Examples are exempt — see B5.

N4. TERMINOLOGY CONSISTENCY
    A concept that appears multiple times uses the same term every
    time within this output. No synonym-switching mid-section.

N5. NO SILENT OMISSIONS
    Every source block must have a corresponding output block. The
    only exceptions are list expansion (B4), recap-rule appends
    (X2), custom-instruction expansions (X3), and explicit
    custom-instruction drops.

N6. ACADEMIC REGISTER
    Output reads as publishable textbook prose: precise, clear,
    grammatically correct, logically ordered. No slang, no hand-wavy
    claims, no informal asides outside the chosen tone profile.

N7. MATHEMATICAL CORRECTNESS
    All LaTeX is syntactically valid. Inline: $...$. Display:
    $$...$$. Chemistry: \ce{{...}}. Never alter equation content
    unless explicit re-derivation was requested.

N8. STRUCTURAL FIDELITY
    Heading hierarchy and section ordering match the source unless
    the STRUCTURE parameter is "reorganize". Even then, never
    reorder content in ways that break cause-effect or derivation
    chains.

PRIORITY 4 — PER-BLOCK-TYPE RULES
═══════════════════════════════════════════════════════════════════

B1. BODY  (type=body → output type:"body")
    Completely rewrite the prose per the active intensity. Vary
    sentence structure, vocabulary, transitions. Preserve every
    fact, number, named entity (N2, N3). Wrap inline math
    expressions in $...$ if not already.

B2. HEADING  (type=heading → output type:"heading")
    Heading-naming mapping:
      • Source heading = "Concepts" or core-theory intro
        → output: "Concepts"
      • Source heading = "Examples" / "Worked Examples" /
        "Sample Problems" / "Solved Examples"
        → output: "Let's Solve"
      • All other headings → preserve source text verbatim
    Output only the heading text; hierarchy level is implicit.

B3. KEY_POINT  (type=key_point → output type:"key_point")
    Concise (≤ 3 sentences). Rewrite while preserving the central
    claim word-for-word in meaning. No new claims, no expansion.

B4. LIST  (type=list → output M × type:"list_item")
    One "list_item" per source-numbered item. Preserve item count
    exactly. Never merge a list into a body paragraph. Never
    include "1." "2." prefixes (numbering is structural).
    Source:  [LIST] 1. Foo  2. Bar [/LIST]
    Output:  {{type:"list_item", content:"rewritten Foo"}},
             {{type:"list_item", content:"rewritten Bar"}}

B5. EXAMPLE / WORKED_EXAMPLE
    (type=example or worked_example → output type:"body")

    NUMERICAL & PHRASING SHIFT (academic team requirement):

    E1. Change ALL numerical values to NEW values. Keep concept,
        difficulty, structure, and variable names identical.
    E2. Rephrase the problem statement entirely — it should read as
        a new question, not a paraphrase.
    E3. Re-work the solution end-to-end with the new numbers. The
        final answer must be mathematically correct for the new
        inputs.
    E4. Output type is "body" (we don't emit an "example" type).
    E5. Numerical fidelity rule N3 does NOT apply inside example
        blocks. It DOES apply everywhere else.

    Example transformation:
      Source: "Find F when m=2 kg, a=3 m/s². Solution: F=ma=2·3=6 N."
      Output: "Find F when m=5 kg, a=4 m/s². Solution: F=ma=5·4=20 N."

B6. FLOWCHART / PROCESS DIAGRAM (described in source prose)
    Reconstruct using one of:
      • Numbered stages (linear flow):
        1. Stage A: ...
        2. Stage B: ...
      • Decision branches (conditional):
        1. Stage A: ...
        2. Decision — Is X true?
           - If yes → Stage C
           - If no  → Stage D
      • Comparative table (2+ parallel paths):
        Use this when the flowchart shows side-by-side processes.
    Pick the structure that preserves the original logic best.

MODE BEHAVIOURS:

  • mode = "append_per_section"
    For each topic regenerated, append at the end:
      {{ "type":"heading", "content":"<target_heading>" }}
      {{ "type":"body",    "content":"<regenerated content>" }}
    Content is sourced from matching source blocks if present, OR
    generated from the topic's own content (no hallucination — must
    be derivable from this topic).
    Cap per `max_items_per_section` if specified.

  • mode = "split_distribute"  (anti-plagiarism redistribution)
    The source contains a list of bullets, typically at chapter end.
    For EACH bullet:
      1. Identify which topic/section the bullet semantically
         summarises (match concepts/keywords against earlier
         sections).
      2. Embed the bullet INSIDE that section as a single
         "<embed_as>" block (default "key_point") with the prefix
         "[recap+<rule_id>] " in the content. Example:
           {{ "type":"key_point",
             "content":"[recap+pts] Force is the product of mass
               and acceleration." }}
      3. Do NOT emit the original chapter-end list anywhere in
         output. The block has been fully redistributed.
      4. If a bullet cannot be confidently matched to any section,
         append it at chapter end under heading "Additional Points"
         (fallback — nothing is dropped).

  • mode = "append_chapter_end"
    Append at the very end of the chapter output, after all topics.

RULES THAT APPLY TO ALL RECAP CONTENT:
  • Honor N1–N8 absolute rules (no hallucination, no number drift,
    consistent terminology, academic register).
  • Recap blocks are EXEMPT from BLOCK COUNT INTEGRITY default
    (they are accounted under exemption X2).
